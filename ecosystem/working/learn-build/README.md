# Learn Build — workstream

The **build** track for the Learn pillar: turning the design (`../learn-mechanisms/`) and the outcomes (`../Learn feels and needs discovery.md`) into a working thing. Living layer.

Where discovery asks *whether the pains are real* and the mechanism doc explains *how each move works*, this track answers *what we build, where, and in what order.*

**Contents:**
1. **`00-module1-demo-plan.md`** — development plan for the **Feelings & Needs Module 1 demo**: a *fully-working, not-yet-user-tested* version. Scope, build placement, screen/flow spec, content inventory, data model, milestones. **v0.3 (2026-08-01).**
2. **`01-module1-wireframes.html`** — low-fidelity wireframes for the demo (open in a browser). Day-1 frame · the daily loop (breathe → notice → name → need → small step) · the optional loop repeat + sitting recap · the distinction catch · the graduation door. Companion to the plan's §4.

**Settled inputs (2026-08-01):** built as a **tool inside Tracker** now, migrating to Learn's standalone app later (decision log — Tracker as staging ground); **LLM-free** for the demo (the distinction-catch runs on an authored lexicon); **scope = tiers 1–3 live, tier 4 storytelling not built and hidden from users** until Reflect is near. The daily loop **opens with a short skippable breath** and supports an **optional bounded repeat** for plural feelings (parallel passes, never related — that's deferred tier-4 work).

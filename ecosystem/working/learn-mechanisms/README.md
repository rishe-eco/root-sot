# Learn Mechanisms — workstream

The **mechanism / process-anatomy** track for the Learn pillar. Where discovery (`../learn-discovery/`) asks *whether the pains are real in users*, this track asks *how the module's moves actually resolve them* — the causal mechanism, the system each process sits in, its preconditions, failure modes, observable signals, and dials. The two run in parallel and feed each other.

Living layer — not canon. Graduates to `../../canon/04-research/` (companion to `00-evidence-summary.md`) once a process's anatomy stabilizes.

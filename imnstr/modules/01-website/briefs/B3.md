## What to build

Plan §5 B3 is the spec. These points settle what it leaves open:

- **Where things go.** Routes in `routes/log.tsx`, mounted with one line in `app.ts` (not `server.ts`). Views in `views/log.tsx` and `views/entry.tsx`, through the existing `Layout` and `page()`. `shared/doc.ts` is new: it is shared with B5–B6's admin bundle, so it imports nothing from `lib/` and nothing Node-only.
- **Already built, reuse it:** `lib/dates.ts` (`formatEntryDate`, `feedDate`), `lib/switch.ts` (kinds `log` and `entry` exist), `lib/ids.ts` (`isId`), `lib/limits.ts` (page and feed size), `lib/clock.ts`. `Layout` already links the feed (`rel="alternate"`) and the nav already points at `/log` and the feed. Check those links now resolve; don't re-add them.
- **Seeding.** The CLI and the tests share one insert, `insertPublished()` in `lib/entries.ts`. The CLI is `scripts/seed-entry.ts`, run with `npx tsx`, plus an npm script `seed-entry`. **For e2e, add `POST /__test/entries`** to `routes/test.ts` (mounted only under `E2E_CLOCK=1`, like the clock), calling the same function, and a `DELETE /__test/entries` to clear the table between tests. No other write path in this stage.
- **Cursor.** `?before=<id>` (PD-25). An id that is malformed, unknown, unpublished or of the other language gives that language's 404. Page by `(first_published_at, id)`, with a test of two entries in the same millisecond across a page boundary.
- **Bidi (PD-8), and S-2 from B1.** `lib/bidi.ts` is the one place isolation happens. Also route the landing page's inline Latin (e.g. "Root" inside `content/site.fa.ts` lines) through it, and recheck the Persian placeholder copy. Only `latinName` and the owner are isolated now.
- **Feed (PD-24).** Built by hand, escaping every value; no XML dependency. The `<updated>` of an entry is its `updated_at`. `Content-Type: application/atom+xml; charset=utf-8`. The feed is a public route: no cookie read, ETag as other pages.
- **The 200% reflow check.** Every new page's e2e calls `expectNoSidewaysScroll(page, 360)` **and** `expectNoSidewaysScroll(page, 180)`, in both languages and both schemes, with the 21-entry log and a long-paragraph entry among the cases.
- **No count anywhere** (AC-5, AC-30): no "N entries", no page number, no "latest" on the landing page. Assert on labels and markup, not bare digits: a date is not a count.

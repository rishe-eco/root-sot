## What to build

Plan §5 B5 is the spec, with one change, which the founder decided at this launch: **the design wins over the plan's row actions.** Rows carry no Unpublish, Republish or Copy link. The rest settles what the plan leaves open.

**Server**
- `lib/publish.ts` as PD-11 says, for any table with the shared columns, so B7 reuses it. A new row is `INSERT … ON CONFLICT (publish_key) DO NOTHING`, then a read by key: never check first. Insert-and-publish is one transaction. **An existing key changes nothing** and returns that row as it is. Once a draft is saved, the client works by id (B6).
- **Every write moves `updated_at`.** Only the first publish sets `first_published_at`. `PUT` never touches it or `state`, and never changes `lang`.
- Entry routes live in `routes/admin-entries.ts`, mounted **inside `adminApiRoutes`, after the guard** (S-12). `app.ts` needs no new line; say so in item 4. Add `GET settings` there or beside `/settings/independence-note/dismiss`. `lastLanguage` defaults to `en`.
- **S-11:** after every router, a catch-all answers `{code:'NOT_FOUND'}` 404 for an unknown `/admin/api` path. Signed out, it stays a 401. The 401 test skips `ALL` routes, so add a test for both cases. Leave unknown `auth/*` paths as they are, and say what they answer.
- **Validation order:** `LANG_INVALID`; then `REQUEST_INVALID` for a `publishKey` that isn't a UUID, or a title that isn't a string or holds control characters; then the body. For the body, drop paragraphs with no content (**S-4**, a `normalizeDoc` in `shared/doc.ts`, also run by the client in B6). Refuse with `DOC_INVALID` for XML-forbidden control characters (**S-5**) and for a body over `limits.bodyMaxBytes`. Answer `BODY_REQUIRED` when nothing but whitespace is left (`docHasText`). A body nginx would refuse never reaches the app, so S-9 stays open, and **don't touch `deploy/nginx/imnstr.conf`**: it's a stop file.
- **The list** (`GET entries?before=<id>`): `{entries, olderBefore, now}`. The order is `COALESCE(first_published_at, created_at) DESC, id ASC`, so it matches the dates shown and never-published drafts sit where they were started. Pages of `limits.pageSize`, cursor as in `listPublished`. `now` comes from `clock.now()`, for the year rule. Each row has `excerpt`: the body's plain text, ~120 characters, cut at a word. No count, no total, no "n of m".
- `setting.last_language` is written on every save and every publish, in the same transaction.

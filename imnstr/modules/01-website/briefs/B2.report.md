## 4. Decisions
- **Prebuilt binary:** `node_modules/better-sqlite3/prebuilds/` holds `linux-x64.node` (glibc), plus linux-arm64, linuxmusl-x64/arm64, darwin, win32. node:24-slim is Debian glibc x64, so it loads `linux-x64.node`. No toolchain, no build stage (replaces the plan's build stage, as the card says).
- **Certificates:** `certbot certonly --nginx` with a bootstrap conf, then swap the symlink to the final conf; replaces the plan's `certbot --nginx` and its sync trap.
- **Nginx zone:** `imnstr_auth:1m rate=30r/m`, `burst=10 nodelay`, 429 on refusal. The card gave no numbers; B4a can tune them. `ssl_session_cache` is named `imnstr_tls`, also prefixed to avoid a clash across the box. Added `client_max_body_size 1m` (nginx default; stated explicitly, B5/B7 may raise it).
- **Symlinks into the repo** (`sites-enabled/imnstr` -> `/srv/imnstr/deploy/nginx/...`) rather than copies into `sites-available`; the plan's file path said `sites-available`. Reload stays a separate checked step. The founder may prefer copies.
- **backup.ts refuses an existing destination** and opens the source through `openDb` (so it also runs pending migrations, harmless on the live DB, and sets busy_timeout). The copy is opened read-only for the check.
- **backup.sh** takes the local backup first and then fails if `BACKUP_REMOTE` is unset, so the local copy exists even when exit is 1. rsync only sends `imnstr-*.db`. `APP_DIR`/`BACKUP_DIR` overridable by env.
- **Unit test** strips comment lines before asserting, so comments may name `add_header`/`default_server`. It also covers the bootstrap file, the 1.18 `http2` spelling, and the Dockerfile/package.json/.dockerignore essentials.
- Cron setup in the README uses `/etc/cron.d/imnstr-backup` with `BACKUP_REMOTE` set in it.
- Healthcheck reads `PORT` (default 4100).

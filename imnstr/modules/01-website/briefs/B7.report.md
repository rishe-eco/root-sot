## 4. Decisions the card didn't make

- **Show links.** Text from a locale string, plate 4's "The show on {platform}" and plate 13's "برنامه در {platform}", with the platform as the content file spells it, isolated. Drawn as `big-row` rows at `--size-title`, not call-to-action size (the 34 px size wrapped at 360 px). The intro is `podcast.lede` in the locales, taken from the plates, not in `content/site.ts`: the file holds the name and the links only. The desktop-only "New episodes land on YouTube first." isn't built.
- **Refusal order.** `LANG_INVALID`, key shape, `publish` type, then the fields in the form's order (name, description, tags, date, links, with `LINK_NOT_HTTPS` per link), then, only for a publish, the PD-23 four. On `PUT` to a published episode the same four apply, and an empty list there is `LAST_LINK`, not `LINK_REQUIRED`.
- **More than two non-blank tags** is `TAGS_ONE_OR_TWO` on any save (two columns, nowhere to keep a third). Tag cap 100 (the card gave none). Name cap = the title's 1,000.
- **Links.** A row with nothing in it is dropped. A URL with no label is `REQUEST_INVALID`. A label with no URL is `LINK_NOT_HTTPS`. The URL is stored as typed, trimmed; `isHttpsLink` also refuses `https:example.com` (which `new URL` accepts) and any space or control character. Position bands are 0 and 1000, so a save never collides and positions don't grow.
- **Date.** On `POST`, absent or `''` is today in `SITE_TZ`. On `PUT`, absent or `''` keeps the episode's own. The form's buffer keeps `''` until the person picks a day, so text kept overnight is never pinned to yesterday.
- **After a confirmed write the new-episode form closes.** Save draft and Publish both clear the buffer and the section says what happened. Entries keep their editor open after Save draft. I chose this because a draft is on the server and a form that kept its key and row id after that would reopen as "New episode" holding an old draft.
- **Confirmation words, on the entry's pattern.**
  - New publish: "Published. It's on the podcast page." with where (`/podcast` or `/fa/podcast`), Open and Copy link.
  - Draft saved: "Draft saved. It's in Podcast, not on the site. Open it from any signed-in device."
  - Saved: "Saved. The episode keeps its date and its place." (plate 11).
  - Republish: "Published, at 3 Oct 2026." and "It's back in its place on the podcast page." (plate 12).
  - Unpublished: "Unpublished. It's in your podcast list as a draft."
  - Before a republish: "Publishing puts it back at <date>, its date. It keeps its place on the podcast page."
  - Failures: signed-out and offline are plate 12's and F-16's; NAME_REQUIRED and REQUEST_INVALID get episode wording, because the shared messages are about passkeys.
- **List.** Reuses the entries list's CSS classes. "No name yet" for an unnamed draft, a "Persian" pill for the language (AC-42).
- **Chips.** Shown per link while that link's label is blank. **Remove** is on each link when there are two or more rows, as the card says, and the server's `LAST_LINK` covers removing down to nothing.
- **Refusals at the field.** The form checks links before sending (https, and a label for an address) and focuses the field. The server's `LINK_NOT_HTTPS` is still handled as a notice if it ever arrives. The suggestion drops a typed scheme and puts `https://` in front; with nothing to build from it uses the plate's example.
- **Offers.** The Podcast section opens itself when the page opens with text to offer back (kept text or edit changes), so an offer is never hidden in a collapsed list.
- **Shared code.** `Said` and `PublishedNotice` moved to `writer.tsx` with the card's list. `LanguageControl` takes a radio `name`, since two forms on a page would otherwise be one radio group. The episode form's `LeaveDialog` and `EditOffer` are written for episodes, not parameterised.
- **`buffers.ts` generics.** Overloads keep `reduce(snapshot, event)` and `createBuffers(storage, 'entry')` as they were, so `buffers.test.ts` is untouched.
- **Microdata set** (for the verify's validator run): on each `PodcastEpisode`: `name`, `description`, `datePublished` (a `<time datetime="YYYY-MM-DD">`), `keywords` (one per tag), `url` (one per link pill), `inLanguage`, `partOfSeries` (a nested `PodcastSeries` with `name` and `url`, the page's own address). No episode number: nothing counts.
- **Hono's JSX hoists `<meta>` and `<link>` into `<head>`**, so the series' markup is written as an escaped string (`views/podcast.tsx` says why); `podcast.test.ts` checks nothing with `itemprop` is in `<head>`.
- **Public order and cursor** use `date`, then `id`. The cursor must be a published episode of that language.

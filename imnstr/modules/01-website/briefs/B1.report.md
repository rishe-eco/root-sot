### 4. Decisions the card did not make
- **Fonts, and the stop rule.**
  - The Arabic subsets of Estedad and Vazirmatn do contain Persian digits, ZWNJ, ، and the Persian letters, which I checked from the cmaps with fontTools.
  - They do not contain « », space, `.`, `:`, `-`, `—` or ASCII digits. Those are in each family's Latin subset.
  - I read the card's "if they don't, stop and report" as aimed at the families, not at the subset split. Each Persian family covers everything once both subsets are loaded.
  - I ship the Arabic and Latin subsets for Estedad (500/700/800) and Vazirmatn (400). Bricolage uses 500/600/700/800 and Newsreader 400, all Latin only.
  - Please confirm that reading of the stop rule.
- **unicode-range.** Each face's range is its exact cmap, because Fontsource's ranges overlap (its Latin face claims U+2000–206F, which includes ZWNJ). With Fontsource's own ranges the e2e probe also passed in Edge, so exact ranges are safety by construction, not a fix for a fault I saw. The CSS comment says so.
- **Hashed assets:** a startup manifest, no build step.
  - `lib/assets.ts` hashes each file's bytes (sha256, 10 hex characters) into `/assets/<name>.<hash>.<ext>`.
  - The stylesheet is the four CSS parts joined, with font `url()`s rewritten to hashed paths before the stylesheet is hashed. It serves with `immutable` caching for a year.
  - Unhashed or unknown asset paths get the designed 404. Licence text files are not served.
- **`/fa`** redirects with 308 to `/fa/`, so there is one address. Redirecting is not by `Accept-Language`.
- **`SITE_ORIGIN = 'https://imnstr.com'`**, a constant in `lib/switch.ts`, for absolute hreflang URLs. The plan lists no env var for it.
- **Header nav on phones** drops Feed (the footer keeps it), as the design's phone plates do, so the wordmark and nav fit 360 px. Landing has no header wordmark; the h1 hero links to `/`.
- **HSTS** is `max-age=63072000`, with no `includeSubDomains` or preload until the founder asks.
- **Cache-Control:** `no-cache` on pages (404 included), `no-store` for `/admin*` (forced), `no-store` on `/healthz`. ETag only on 200 pages, from Hono's `etag()`.
- **Extra trigger.** `episode_publish_needs_link_on_insert` refuses inserting an episode already published, which can never have a link yet. B7 must create the draft, add the link, then update. RAISE messages are `LAST_LINK` and `LINK_REQUIRED`, for the code map.
- **Schema constraints I added** beyond §6.3:
  - `auth_throttle.id` is `CHECK (id = 1)`, with the one row inserted in the migration.
  - `episode.date` is `NOT NULL` with a `YYYY-MM-DD` GLOB CHECK.
  - Credential boolean flags are 0/1 CHECKs.
  - `session.opened_by` and `device_credential` are `NOT NULL`.
  - Record tables use `WITHOUT ROWID`, a composite primary key and a `lang` CHECK, and nothing else.
- **Episode columns.** "Like entry" is read as id, lang, state, dates and publish_key. Episode has name/description/tags/date instead of title/body. Name, description and tags are nullable, since a draft needs only a language.
- **`POST /__test/clock`** takes `{now: ms|null}` and returns `{now}`. A bad body gives `{code:'CLOCK_INVALID'}` with 400. That code is not in §6.2, because it is test-only.
- **Arrows are inline SVG.** No font has the arrow glyphs, and a text arrow would be a fallback-font glyph (AC-40). CSS mirrors them with `scaleX(-1)` in Persian.
- **Favicon** is `href="data:,"` so the browser does not request `/favicon.ico` on every page.
- **`<mark>` highlight.** The row hover fills at once with no sweep, since motion is B9. A global reduced-motion safety rule is in `base.css`.
- **Source-scan unit tests.** `tests/unit/house-rules.test.ts` checks:
  - no `new Date()` or `Date.now()` outside `lib/clock.ts`;
  - no inline script, `style=` or `on*=` in the views;
  - no physical CSS properties;
  - no colour literals outside `tokens.css`;
  - no `px` in the stylesheets.
- **Real fallback-font check.** The e2e checks (AC-40) use the DevTools protocol (`CSS.getPlatformFontsForNode`) to prove every glyph is drawn in a web font, rather than relying on `document.fonts.check`.
- **Dev dependencies** are only the four the card allowed, plus §6.6's `typescript`, `tsx`, `vitest`, `@playwright/test`. I did not add `vite` or `@axe-core/playwright`, since B1 has no use for them. Runtime is `hono`, `@hono/node-server` and `better-sqlite3`.
- **Playwright default port.** `playwright.config.ts` falls back to port 4100 with `reuseExistingServer: false` if `PORT` is unset, so a lane that forgets `PORT` collides rather than reusing someone else's server.

### 5. Where the plan or card was wrong or vague against the code
- **Plan §4 and PD-26** say to ship "the Arabic subset" of the Persian families. That is not enough: «» and Latin punctuation need the Latin subset too.
- **Plan §5 B1 and the card** do not say what an episode's columns are: "like entry" is ambiguous, and entry has `title` and `body`. See item 4.
- **hreflang** needs an absolute origin, but no env var supplies one.
- **The card's "401 enumeration test"** and "every admin route" rules have nothing to attach to in B1. There are no admin routes yet, so B4a must create that test.
- **The nav "Feed" link and `/log`/`/podcast`** point at routes that are 404s until B3 and B7. That is intended, but the e2e checks only that the links exist.
- **Inline Latin in Persian prose** (for example "Root" inside a Persian project line) is not wrapped in `<bdi>`. Only names flagged `latinName` and the owner name are. The general isolation belongs to `lib/bidi.ts` in B3, and B3 should revisit the placeholder Persian copy.
- **D-2 and the schema:** `entry.id` and `episode.id` are text, and `auth_code.id` is text too, so no id in B1 is sequential.
- **Brief-common says `npm install` may strip `"dev": true`.** This was a fresh install, so I committed `package-lock.json` as generated.
- **Line endings.** Git warns that LF will become CRLF (core.autocrlf on this machine), and there is no `.gitattributes`. B2 may want `* text=auto eol=lf`.

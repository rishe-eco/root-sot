## What to build

The plan's B0 section stands, with these corrections from the code check:

- **`client/e2e/helpers/api.ts` also hard-codes `http://localhost:4000/graphql`** (line 7); the plan names only `globalSetup.ts`. Put the port arithmetic in one small module (say `client/e2e/ports.ts`) that `playwright.config.ts`, `globalSetup.ts` and `helpers/api.ts` all import. Grep `client/e2e` for `4000` and `5173` afterwards: none may remain.
- **`tsx` is not installed.** `nodemon src/index.ts` runs through `ts-node` (a dev dependency). The API web server is `npx ts-node src/index.ts`, without watch (Decided 1). Before you write the command, check that it starts in your worktree (the plan's open unknown), and say so in the report.
- **`.gitignore` needs no change:** `api/.gitignore` already ignores `*.db` at any depth (`git check-ignore` confirms it for both `api/prisma/e2e.db` and `api/prisma/prisma/e2e.db`). Don't add a root line. Report where the file actually lands: Prisma resolves `file:./prisma/e2e.db` relative to `schema.prisma`, so expect `api/prisma/prisma/e2e.db`.
- **The environment goes through each `webServer` entry's `env` and `cwd`,** never as inline `VAR=x cmd`, which doesn't run in Windows' shell. The explicit `env` overrides anything inherited, which is what makes "never pass `DATABASE_URL` through from the shell" true. The API entry's `cwd` is `../api`, and it chains `npx prisma db push --skip-generate --force-reset && npx ts-node src/index.ts`.
- **The guard:** the config builds `DATABASE_URL` from a constant and throws, before `defineConfig` returns, unless it ends in `e2e.db` and names none of `dev.db`, `test.db` or `prod.db`. Plant a violation once, see the throw, and revert it.
- Each `webServer` entry's `url` is the port it waits on (API: `/graphql`, which answers GET with a landing page; check that it does). The web server gets `--strictPort`. `use.baseURL` comes from the web port.
- `client/e2e/README.md`: short. The variables, their defaults, the two slots (A `4010`/`5183`, B `4020`/`5193`), `E2E_REUSE=1`, and the Windows note below.

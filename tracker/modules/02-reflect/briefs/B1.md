## What to build

Exactly plan §5 B1. These are the corrections and settlements from the code check:

- **Placement.** `LoopState` ends at `schema.prisma`:739 and Noticing's banner is :741. Your block goes between them. Noticing's fence slices from `Impact · Noticing (Act 1)` to EOF, so nothing of yours may sit after it.
- **The migration.** Prisma relations on `User` are virtual, so the SQL creates the four tables, their indexes and foreign keys, and touches no other table. Open the generated `migration.sql` and confirm this. Then run CI's check from `api/`: `npx prisma migrate diff --exit-code --from-migrations prisma/migrations --to-schema-datamodel prisma/schema.prisma --shadow-database-url "file:./prisma/.tmp-shadow.db"`. Delete the shadow file afterwards.
- **The pack mirrors Noticing's,** with `Locale = "en" | "fa"` and a registry that refuses an unknown version or locale rather than falling back. The lexicon's shape is `{ family, triggers: string[] }[]`. It carries no hints: the offer line is one template with a `{word}` slot.
- **The `fa` lexicon's variants.** B3's matcher folds Arabic-keyboard letters (`ي ك` → `ی ک`) and reads ZWNJ as a space, so an Arabic-keyboard spelling is redundant after normalization. Author those variants anyway, as the plan says, and also the joined spelling with no ZWNJ (`میکنه` beside `می‌کنه`), which the fold does *not* cover. Flag the redundancy in report item 5.
- **"No trigger nests across two families"** means that after normalization, no trigger of one family equals another family's trigger or appears inside one of its triggers. Normalization is NFC, lower case, the Arabic folds, ZWNJ to a space, and collapsed whitespace. Copy that fold into the test file with a comment naming its source. A Reflect test must not import Noticing's service. Within one family, normalized duplicates are allowed, since they are the variants.
- **AC-19's scan** walks every string in both surfaces except the lexicon. `en`: `/\bwhy\b/i` and `/deepest/i`. `fa`: `چرا` and `عمیق‌ترین`, checked on the normalized text, so `عمیق ترین` fails too.
- **The fences' slice** runs from `Reflect · the observer recount` to `Impact · Noticing (Act 1)`. If either marker is missing, the fence throws, as Noticing's does. The imports half reads every `.ts`/`.tsx` file under `api/src/services/reflect` (the folder may not exist yet; treat that as empty) and `api/src/content/reflect` as text, and every file under `client/app` for `content/reflect`.

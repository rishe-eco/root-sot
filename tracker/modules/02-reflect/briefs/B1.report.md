## 5. Where the plan, card or brief was wrong, vague or incomplete

1. **The `fa` Arabic-keyboard variants are redundant.** B3's fold turns `ي ك` into `ی ک`, so the listed Arabic-keyboard spellings (`هيچ‌كس`, `بي‌ادب`, `كنترل‌گر`) normalize onto their Persian twins. The ZWNJ variants are redundant too (ZWNJ becomes a space), but the joined spelling (`میخواست` beside `می‌خواست`) is not covered by the fold and is a real addition. Authored as the card says; they could be dropped.
2. **The card's plant `a journal Journal relation` cannot be planted as written.** Prisma refuses a relation field with no inverse on `Journal` (`prisma db push` in the test global setup fails, so the whole vitest run errors before any test). The plant needed `journalId`, a named relation, and an inverse on `Journal`. Same would hold for any future plant of a relation.
3. **`npm run typecheck` in `api/`.** The card is right that it's `npx tsc --noEmit`; the brief-common line is stale, as the card said.
4. **Line endings.** `schema.prisma` is CRLF in the working tree (`core.autocrlf=true`), so any scripted edit must match `\r\n`. `prisma migrate dev` also rewrote `migration_lock.toml` (LF/CRLF churn only); I restored it with `git checkout` and did not commit it. A lane that commits it will show a spurious diff.
5. **`prisma migrate dev` hangs when not given stdin.** My first run, issued before the schema edit landed, never returned and left three processes (`npx`, `prisma`, `schema-engine`) holding the dev database; a later run failed with `database is locked` until I killed them (all mine, confirmed by path). Running with `--skip-generate < /dev/null` and `timeout` worked.
6. **`DATABASE_URL` is `file:./prisma/dev.db`**, which Prisma resolves relative to the schema folder, so the dev database lives at `api/prisma/prisma/dev.db`. It is gitignored. Not wrong, but easy to look for in the wrong place.
7. **The card's nesting rule** is silent on whether containment is by substring or by word. I used substring (stricter). If B3 matches on word boundaries, a looser rule would also pass; the stricter one cannot hide a nest.
8. **`ARABIC_FOLDS` in `catches.ts`** is documented as copied from `feelingsNeeds/distinctions.ts`; I copied from `catches.ts` as the card said. They are identical today, as far as I read.
9. **The card says `LoopState` ends at :739 and the banner is :741.** Both held at `5fd71c9`.

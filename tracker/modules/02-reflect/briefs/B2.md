## What to build

What §5 B2 says, with these settled against the code:

- **The token guard.** `api/src/index.ts` sets `ctx.auth` to `{ kind: "session" }` or `{ kind: "apiToken", scope }`. `mutations.ts:1279` already has a private `requireSession(ctx)` for token management, with its own message. Put Reflect's wrapper in `api/src/graphql/auth.ts` as **`requireReflectSession`** (decision 1). It runs inside `requireAuth`, throws §6.2's token message when `ctx.auth?.kind !== "session"`, and never `Unauthorized`.
- **Test contexts.** `makeCtx` in `api/src/test/helpers.ts` sets no `auth`, so every Reflect call made with it would be refused. Build session and token contexts in the Reflect test file, as `apiTokens.integration.test.ts` does. Leave `makeCtx` alone.
- **Read-scope tokens on a mutation.** Through the running server, `index.ts`'s plugin refuses these first, with its own read-only message. Integration tests call resolvers directly, so they reach your guard. Test the guard there, and don't assert the plugin's message.
- **`clearDb`** gets `reflectReading`, `reflectMoment`, `reflectEntry` and `reflectState`, ahead of `user` (B1 left this to you).
- **Where the SDL goes.** Types and enums go in a `# ── Reflect` block placed just before `# ── Learn · Feelings & Needs (Module 1)` (`typeDefs.ts`:1595). Operations go in `type Query` and `type Mutation` under a `# ── Reflect` comment. Noticing's fence slices `:1822` to `type SkillOverview {`, so keep everything out of that range.
- **"Every name contains Reflect"** means operation names and type names. Argument and field names (`entryId`, `scene`) can't. The fences find arguments by the operation they sit on. Noticing owns `NtcReflectCopy` and its `reflect:` field; a Reflect type is one whose name *starts* with `Reflect`.
- **The fence's field checks** read output `type` blocks only. `saveReflectEntry`'s `precheckWhen` argument is allowed.
- **`reflectContent`:** `prompts` hold the pack's `story`, `feelings`, `reality`, `close` and `interpretation` copy, and never `lexicon`. `otherLabel` is F&N's `loop.nameOther` from the pinned pack.
- **The import fence (AC-47)** matches a model accessor on any client variable (`prisma`, `tx`), for example `/\b\w+\.(action|interval\w*|goal|journal\w*|loop\w*|frameCompletion)\.\w+\(/`. Plant one violation to watch it fail.
- **The token-refusal unit test** finds every `Query` and `Mutation` resolver with `/reflect/i` in its name. It asserts the set is non-empty and holds all 14 operations.
- **No `console.*`** anywhere in `services/reflect`. No error message carries a field's text.

## Decided here

| # | Decision | Why |
|---|---|---|
| 1 | The wrapper is `requireReflectSession` in `graphql/auth.ts` | A second `requireSession` would sit beside the token-management one in `mutations.ts` with another message |
| 2 | `ensureReflectState` writes on the first `startReflectEntry` only. Reads before then serve `CURRENT_VERSION` of both packs without writing | The plan says "on first start", and reads stay read-only. It runs under `withUserLock("rfl-state:" + userId)` |
| 3 | GraphQL enums `ReflectWordSource` (`PALETTE`, `OWN`), `ReflectMet` (`MET`, `UNMET`, `NOT_SURE`), `ReflectPrecheckWhen`, `ReflectPrecheckBefore`, stored lowercase as the schema comments say | A bad value is refused by the schema, with no new §6.2 message |
| 4 | A move to the current step returns the entry unchanged | A double tap on Next must not fail. It isn't a forward move, so B3 surfaces nothing on it |
| 5 | Bounds count `.length` (UTF-16 units) | The same count as the browser's `maxLength`, so client and server agree |
| 6 | Services write `createdAt` and `closedAt` from `new Date()` explicitly. Tests use `vi.useFakeTimers({ toFake: ["Date"] })` with `vi.setSystemTime` | Prisma's `@default(now())` is set in the engine, out of reach of a faked clock. No test in the repo fakes the clock yet |
| 7 | The `before` cursor orders by `createdAt` desc, then `id` desc. A `before` that isn't owned gives `Not found` | A stable order under equal timestamps, and no existence leak |
| 8 | No text is trimmed; only `""` becomes null | The person's text is stored as typed |
| 9 | No new dependency | none needed |

## What to build

What §5 B4 says, with these settled against the code:

- **Fetch with `useApi`, as F&N and Noticing do,** never Apollo hooks. Only `ActivitiesPage` uses Apollo, so a Reflect page that never touches the cache meets D-9's eviction rule by construction. Say so in a comment at the delete site, and in the report. Flagged for verify, because the plan names "the Apollo cache".
- **Documents in `client/app/api/queries.ts`,** as the plan names them. `queries.ts` has no Reflect documents today. Select only the fields §6.1 lists. `ReflectContent.limits` is `{ scene, story, storySoftLine, whenText, reading, camera, ownWord, close, momentsCap, readingsCap }`.
- **The layout.** `InternalPageLayout` has no slot for a step bar: it takes `title`, `backLink`, `actions` and `children`. Put the bar at the top of `children`, as a component B5 imports (`ReflectStepBar`, `ReflectFooter`). Put Stop here at the bar's inline end with logical properties (`ms-auto`, `ps-`/`pe-`), so it sits left in `fa`.
- **ConfirmDialog** already puts Cancel first (`flex justify-end`, Cancel before Confirm), so W17 needs no change to it. Use `variant="destructive"`.
- **Committing the pre-check (PD-6).** Leaving the pre-check sends one `saveReflectEntry` with `precheckWhen`/`precheckBefore`, then `moveReflectEntry(to: STORY)`, or `stopReflectEntry` for Not now and Stop here. Send the save even when both answers are blank, so that one path covers every exit.
- **Autosave.** `useReflectAutosave` debounces each field's save by 800 ms through `saveReflectEntry` with that field alone. `flush()` returns a promise that resolves once nothing is pending or in flight, and rejects if a save failed. Next and Stop here `await flush()` first (D-15). A failure leaves the text, shows the not-saved line and **Try again**, and disables Next and Stop here. No `localStorage` or `sessionStorage` for any Reflect text.
- **"Holds written text"** (AC-56), on the calm close: a non-empty `scene`, `story` or `close`, any moment's `whenText`, `feeling` or `need`, or any reading's `reading` or `camera`. Read it from the `ReflectEntry` that `stopReflectEntry` returns.
- **G4's line** reads `openEntry.hasStory` as B2 built it (story text only). The spec now asks "any written text" (AC-53); B6 redefines `hasStory` on the server and the key stays. Draw the "nothing written yet" wording from the spec, not plate 2's "with no story yet" (change note, row 70).
- **The entry route.** On load, `reflectEntry` is null → `navigate("/tools/reflect", { replace: true })` (G15's first half). The step shown is `entry.step`. The calm close is page state after a stop, not a step.
- **The banner** shows when `i18n.language !== practiceLocale` or `reviewStatus === "draft"`, on the home, and on the entry page above the first step body rendered after mount (G17). It has no dismiss.
- **Copy.** All interface strings go under a new `reflect` key in both `common.json`s. The calm close goes under its final keys, `reflect.calmClose.*`, with `"_draft": "B7 replaces these values (P0-1)"` beside them. The prompts come from `reflectContent`, not `common.json`.

## Decided here

| # | Decision | Why |
|---|---|---|
| 1 | `useApi`, with no Apollo cache; D-9's eviction is met by not caching | It's the pattern of every comparable page; there is nothing to evict |
| 2 | The pre-check save is sent on every exit, blank or not | One commit path (PD-6); a blank save is harmless |
| 3 | e2e uses the shared globalSetup user, and each test ends with no open entry (Not now, Stop here, or deleting through the API) | Reflect keeps one open entry per person; specs share the user |
| 4 | A reload on the story is checked after the 800 ms pause, by waiting for the save's network response, not with a sleep | Shows autosave without a timing flake |
| 5 | Branch `reflect-b4-entry-shell`, slot A | No lane is live; no schema |

## What to build

What §5 B5 says, with these settled against the code:

- **Documents.** Widen `REFLECT_ENTRY_FIELDS`' moments to `feelingSource needSource met`; select `interpretationOffer { word sentence }` on the move; widen `GET_REFLECT_CONTENT` to every prompt group, `feelings { id label }`, `needs { id label }` and `otherLabel`. Add the four mutations; `saveReflectMoment` selects `fauxOffer { position conceptId line feelingHints needHints feelingHintsLabel needHintsLabel dismiss note }`.
- **Positions (B2).** A card with no stored row has no position yet. *Add another moment* and *Add another* show only when every card has a stored row and the count is under three, so the first write of a new card is always the next free position.
- **Autosave for rows.** `useReflectAutosave` keys by `"scene" | "story" | "close"`. Generalize it to string keys (`moment:0:whenText`, `reading:1:camera`) on the one queue, with a save function per kind, and keep its tests green. `flush()` before every Back, Next and Finish.
- **When a word commits.** Chips and *Met · Unmet · Not sure* save at once. The *when* line, readings and camera save on the 800 ms pause. An own feeling or need (*other…*) saves on blur, Enter, or `flush()`, never on the pause, so a half-typed word can't surface the faux offer.
- **Met can't be cleared today.** `saveMoment` maps `met: null` to "leave it" (`entry.ts`, B2's decision 5). Make an explicit `met: null` clear it, `met` alone, with an integration test; omitted still leaves it. Flagged for verify: the plan says client only.
- **Back.** Feelings, Reality and Close pass `onBack` to `ReflectFooter`; Back moves to the step before (to the story from Feelings). This covers B4's untested Back slot.
- **Offers** live in page state, from the result that carried them, and are dropped on any move or reload (G11).
- **A `closed` refusal** (`This entry is closed.`, read with `getLastError()`) on any save, move or finish goes to `/tools/reflect` with `replace`, instead of the not-saved line (B4's *Owed*).
- **Finish and after.** Finish flushes, calls `finishReflectEntry`, then `navigate(".", { replace: true, state: { finished: true } })` and shows plate 8. The answer buttons and Skip share one ref lock that is never released, so `answerReflectEntry` is sent at most once. On load with no open entry, `location.state?.finished` shows the done line; otherwise the home, as now.
- **Direction.** Palette labels, hints and the offer's word: `dir="ltr"`. The person's words (shown-back story, folded moments, fields): `dir="auto"`.

# required-headings.txt — the headings `bin/gate` checks in each phase output.
# Version 0.2 · 2026-10-20 · Owner: founder (changes through `revise` on the method, or an accepted consolidation).
# 0.2: fixes found while building `bin/gate`, each accepted by the founder: conditional lines written `when …:`
#   and never failed; done phases warn instead of fail (STRICT OR WARNED, replacing the "not re-gated" note);
#   the Personas and Coverage checks spelled out; `in`/`each` lookups, list splitting and sections made exact.
# Sources: each template in this folder; `skills-plan.md` §0 *The gate* and §5; each skill's `skills/<skill>/reference.md`;
# the *Template sample* section of each IMNSTR trial log (`trial-run/log/`), and `trial-run/findings.md` §10 (F-2).
#
# FORMAT
#   # ...                 a comment; blank lines are ignored.
#   [<pattern>]           starts a block for the files matching <pattern>. Relative to the module folder,
#                         unless it starts with `lifecycle/`. `*` matches within one path segment.
#                         `!<pattern>` on the same line excludes files.
#   h2 <text>             the file has a level-2 heading (`## ` in Markdown, `<h2>` in HTML) whose text
#                         contains <text>.
#   h3 <text>             the same, for level 3.
#   <a> | <b>             either one satisfies the line.
#   in h2 <s>: h3 <t>     the h2 section matching <s> contains an h3 matching <t>.
#   h2 #<n>               the file has a level-2 heading numbered <n> ("## 3. …"), whatever its words.
#   in h2 <s>: cell <t>   the h2 section matching <s> holds a line, list item or table cell whose text,
#                         with Markdown marks stripped, starts with <t>.
#   in h2 <s>: item <n>   the h2 section matching <s> holds a numbered list item <n> ("7. …").
#   in h2 <s>: each h3 has bold <A>, bold <B>
#                         every h3 inside that section holds a line starting `**<A>` (and `**<B>`).
#   each h2 <s>: h3 <A>, h3 <B>
#                         every h2 matching <s> is followed, before the next h2, by h3s matching <A> and <B>.
#                         At least one h2 must match <s>.
#   when <condition>: <line>
#                         a conditional line. The gate can't judge the condition, so it checks <line> and,
#                         when <line> isn't met, reports it as "not checked (<condition>)", never as missing.
#
# MATCHING
#   - Case-insensitive. Before comparing, a heading loses its leading section number ("1.", "6.7 ·", "B1 ·"),
#     Markdown marks (` * _) and HTML tags inside it; runs of spaces become one.
#   - "contains": the required text may sit anywhere in the heading, so "## 4. Suggested — gaps in the spec,
#     for `revise`" satisfies `h2 Suggested`.
#   - Lines are matched in order, each taking the first heading not already taken: each line must be
#     satisfied by a different heading. `h2 Journeys` is not met by
#     "Decisions taken at journeys" when that heading already met `h2 Decisions taken at journeys`.
#   - `in` and `each` lines look a heading up without taking it, so a later line may still take it.
#   - `each` and `each h3 has` lists are split on ", h3 " and ", bold ", since heading words may hold commas.
#   - A section runs to the next heading of the same level or higher. Headings inside code fences
#     (``` or ~~~) don't count, and HTML tags inside a heading count as spaces.
#
# STRICT OR WARNED
#   The gate checks the headings of every input to the phase it is asked about. When that phase's own
#   cell in `status.md` is already `done` (or `closed`, or column 8 at n/n), it is not being opened, so a
#   missing heading, a criterion missing from a Coverage table and an empty Personas table are warnings.
#   When the cell is blank, `STALE` or in progress, they fail. A missing file, a `STALE` input and a
#   branch behind its upstream always fail. (Outputs written before these templates, such as IMNSTR's,
#   then pass their done phases with their gaps listed as warnings.)
#
# BEYOND HEADINGS (bin/gate, not this file)
#   - Personas: the `## Personas` table in `03-journeys.md` needs at least one row. A deliberately
#     empty selection is written as one row, `none — <why>`.
#   - Coverage: every `AC-n` in the spec's *Acceptance criteria* appears in a row of the journeys'
#     *Coverage* table. In a change note, every criterion id in its *Acceptance criteria* appears in
#     some stage's **Acceptance** line; ranges such as "CI-1 to CI-11" count every id in them.

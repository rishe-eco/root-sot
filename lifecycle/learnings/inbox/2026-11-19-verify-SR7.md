## Start a slot's e2e servers once in an e2e-heavy lane
**Rule:** In a lane or review that runs many single e2e specs, start the slot's API and web once with `config.md`'s own commands, run each spec with `E2E_REUSE=1`, and stop them at the end; say so in `brief-common.md`'s e2e section.
**Event:** SR7's lane ran `session.spec.ts` part 2 test by test; each `npx playwright test` paid a 25–60 s `prisma db push` for a fresh scratch database (report part 7). The review's three e2e invocations paid it three times.
**Cost:** about 25–60 s per invocation; several minutes over the lane.
**Scope:** project tracker · skill `build-phase` (card and brief)
**Destination:** `lifecycle/projects/tracker/brief-common.md` (e2e)
**Urgent:** no

## Wait for a dialog to close before clicking a name it shares with the page
**Rule:** In an e2e step that closes a dialog and then clicks a page control, assert the dialog is gone first when the dialog holds a control of the same accessible name; otherwise the click can land in the closing dialog.
**Event:** `session.spec.ts` "capture onto a day" clicked "No date yet" right after the sheet's Add; the sheet's own "No date yet" chip was the only match while it saved, so the fold stayed closed. It passed in the lane and failed 1 of 1 in the review's run; fixed with `expect(dialog).toHaveCount(0)`, then 5 of 5.
**Cost:** one red e2e run and a diagnosis at the review.
**Scope:** project tracker · repo
**Destination:** `tracker/canon/03-engineering/01-testing.md` (e2e conventions)
**Urgent:** no

## Probe a native date field with the keyboard before saving on its change
**Rule:** A control that saves on a native `<input type="date">`'s `change` must be driven by arrow keys in a review, not only by `fill()`: each arrow step emits a complete value.
**Event:** the look-ahead's "Later…" field (`LookAheadRow.tsx`) saves on every change; `fill()` in the lane's e2e sent one value, but one ArrowUp in Edge sent the next date + 1 and moved the row away (`verify SR7`'s throwaway probe).
**Cost:** a keyboard-reach defect owed to a lane (open-work, by MS2).
**Scope:** project tracker · skill `verify`
**Destination:** `lifecycle/projects/tracker/review-checklist.md` §4 (keyboard)
**Urgent:** no

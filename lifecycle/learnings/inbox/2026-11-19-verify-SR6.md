## A page clock past the real date needs a token that outlasts it
**Rule:** When an e2e spec sets `page.clock` ahead of the real date, sign the fresh user's token past that clock (a shared `freshUser.ts` option), and say so in the card's Traps: `authSession.ts` signs out any token whose `exp` is before `Date.now()`, and `page.clock` moves `Date.now()`.
**Event:** SR6's card fixed T0 = 2026-12-01 for `page.clock` (the plan's trap); the real date was 2026-11-19, so the seven-day token read as expired and the client signed out. The lane found it on a failed run and re-signed the token inside `session.spec.ts` with the e2e secret copied from `playwright.config.ts` (report part 4 call 15, part 7). The review confirmed the cause in `authSession.ts` line 65.
**Cost:** one failed e2e run in the lane; the secret now lives in two files.
**Scope:** project tracker · skill `build-phase` (card drafting)
**Destination:** `client/e2e/helpers/freshUser.ts` (a long-lived token option) and `lifecycle/projects/tracker/brief-common.md` (e2e traps)
**Urgent:** no

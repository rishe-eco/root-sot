## `git worktree remove` can outlast the step on Windows
**Rule:** To drop a lane's worktree on Windows, don't rely on `git worktree remove` alone — if it exceeds the call timeout, run `git worktree prune` then `git branch -d`, and delete the leftover directory separately (background it).
**Event:** `git worktree remove .claude/worktrees/sr0-schema-day-rules` timed out at 120 s (exit 143) deleting the worktree's installed `node_modules`; `prune` + `branch -d` + a backgrounded `rm -rf` finished it cleanly.
**Cost:** one timed-out Bash call (~2 min).
**Scope:** skill `verify` (and `build-phase` land), Windows.
**Destination:** `verify`/`build-phase` reference, or `brief-common.md`.
**Urgent:** no

## A card that names a refusal message should say which cases it covers
**Rule:** When a card gives an exact user-facing refusal string, state every case that string covers, so the lane doesn't have to infer whether a second message is wanted.
**Event:** SR0's card named `orderDay`'s "Order applies within one start time." for the cross-start-time case but not the cross-*day* case; the lane spent time reading §2.2 #8 and §6.2 to decide one message covers both (report part 7), and verify had to confirm the reading.
**Cost:** a few minutes of lane time; one reviewer confirmation.
**Scope:** skill `build-phase` (card drafting), method.
**Destination:** `build-phase` reference, or `brief-common.md`.
**Urgent:** no

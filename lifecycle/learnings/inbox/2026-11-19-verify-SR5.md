## Scripted edits on the Windows build machine use Node and match CRLF
**Rule:** On the Windows build machine, script multi-file edits in Node (no Python is installed), and match line ends with `\r?\n`: `core.autocrlf` is true, so the index is LF and the working copy CRLF.

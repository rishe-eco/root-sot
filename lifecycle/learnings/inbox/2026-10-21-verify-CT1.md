## Stop a dev server by its port's PID, never by image name

**Rule:** On Windows, stop a server a review started by the PID listening on its port (`netstat -ano`), never `taskkill /IM node.exe` with a filter.
**Event:** verify CT1 stopped its probe server with `taskkill //F //IM node.exe //FI "WINDOWTITLE eq *"`, which killed every node process on the machine, whatever else was running.

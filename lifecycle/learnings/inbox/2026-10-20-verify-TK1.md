## Free the slot's ports before an e2e run, or a stale build is tested

**Rule:** Before any e2e run in a root-app slot, check that the slot's web and API ports are free (`ss -ltn | grep -E '<api>|<web>'`), and kill whatever holds them. Playwright's `reuseExistingServer` silently serves an old `vite preview` bundle.
**Event:** A `vite preview` left on 4273 by the lane's interrupted run served this review's first two runs. A fix to `Support.tsx` looked like it failed until the process start time (20:05, before the review) gave it away.
**Cost:** one wasted e2e run and a false "fix doesn't work" (about 5 min). A lane would record red/green against the wrong code.
**Scope:** project (root-app)
**Destination:** `projects/root-app/config.md` §2 and `brief-common.md`, through the founder
**Urgent:** yes

## Root `npm run e2e` needs a second `--` to pass Playwright flags

**Rule:** Run one root-app e2e test as `npm run e2e -- -- <spec> -g <name>`. With a single `--`, the inner `npm run --workspace` takes `-g` as `--global` and swallows `--workers=1`.
**Event:** The lane's report part 5 and 7: `-g` failed with "Workspaces not supported for global packages". The review's runs showed `playwright test 27-support.spec.ts` with `--workers=1` gone, and the `-- --` form passed `-g 'TK-1|TK-2'` through.
**Cost:** the lane fell back to `cd apps/web && npx playwright test`; unknown time.
**Scope:** project (root-app)
**Destination:** `projects/root-app/config.md` §2 (the Suites table's single-test command), through the founder
**Urgent:** no

## A retry-on-error helper should name the error the runtime actually throws

**Rule:** When a test fails with "fetch failed" next to a helper that retries a network race, read the `cause.code` before calling it the machine. undici reports a closed keep-alive socket as `UND_ERR_SOCKET`, not `ECONNRESET`.
**Event:** The lane put 25-home's "other side closed" down to this machine's API process. The cause was `e2eFetch` retrying only `ECONNRESET`. After one line, 25-home passed three runs of three, and a logged run showed the retry firing.
**Cost:** the lane reran 25-home twice and stashed its change to compare against `main` (about 6 min). It left a red required spec unexplained for verify.
**Scope:** skill `debug`
**Destination:** `skills/debug/reference.md`
**Urgent:** no

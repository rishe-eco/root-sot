**Scope:** skill `build-phase`

## A scripted replace asserts its anchor is unique
**Rule:** Before a scripted find-and-replace in a source or test file, assert the anchor occurs exactly once, or use the Edit tool, which refuses a non-unique match.
**Event:** `verify B5`: a Python `replace(…, 1)` meant for the new faux-offer test hit an identical line in the earlier chip test. The run then failed in the wrong test, and the file had to be restored and the edit redone.
**Cost:** two confusing runs, about 5 minutes
**Scope:** model behaviour
**Destination:** `lifecycle/skills/verify` (step 3, fixes), or the model guidance in `brief-common.md`
**Urgent:** no
